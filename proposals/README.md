# Proposals

Your own idea, technique or paper, written so that anyone can test it.

A proposal does not need to be proven. It needs to be **testable**: a clear mechanism, a clear claim about compute, and a way to check it. Once a proposal is merged it has the evidence level IDEA ([`CHARTER.md`](../CHARTER.md) §5), and anyone may run a check of it at any time. That includes you, though your own check needs a second, unrelated reviewer.

## How to submit

1. Open an issue with the **Proposal** template. A maintainer assigns an ID (P001, P002 and so on).
2. Copy [`../templates/PROPOSAL.md`](../templates/PROPOSAL.md) to `proposals/P###-<short-name>/PROPOSAL.md`, fill it in, and add any code.
3. Open a pull request. A reviewer checks that the proposal is clear and testable, not whether it will work.
